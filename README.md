# danmagatti.com

Static copy of the danmagatti.com photography portfolio (75 pages: portfolio, travels, clients, blog, videos).

Hosted with GitHub Pages from the `main` branch, root folder. No build step.

- `sitemap.xml` and `robots.txt` are at the root.
- Contact form opens the visitor's email app addressed to danmagatti@gmail.com.
- Google Analytics 4 is loaded on every page.
- `.nojekyll` keeps GitHub from processing the files. `404.html` is the not-found page.
